Lumi

Proactive hazard alerts for blind and low-vision walkers — smart glasses paired with a compact on-device vision-language model.

▶ Watch the demos

What is Lumi?

Lumi senses the environment through Mentra Live smart glasses and speaks concise guidance. A long-press on the glasses toggles between two modes:

Hazard mode
Continuous obstacle warnings that run on the phone in real time — Lumi decides when to speak and keeps each alert to one short spoken sentence.
Command mode
On-demand "describe / read / find X" answered by a cloud VLM, one long-press away.
